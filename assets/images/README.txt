IMAGE PLACEHOLDERS
==================
The site currently uses styled placeholder blocks (.img-ph) wherever the
design calls for a photo. To use real images, drop files in this folder and
replace the matching <div class="img-ph" ...></div> with an <img> tag, e.g.:

  <img class="hero-media" src="assets/images/hero.jpg" alt="...">

Recommended slots & sizes:
  hero.jpg            ~ 1040 x 1160  (home hero, portrait)
  founder.jpg         ~ 720 x 720    (about page, square — your real headshot)
  case-featured.jpg   ~ 1040 x 720   (case studies featured)
  case-1/2/3.jpg      ~ 800 x 500    (case study grid)
  insight-featured.jpg~ 900 x 680    (insights featured article)

Keep files optimized (<300 KB each) for fast loading.
